# 🚀 Быстрый старт — Boot Breaker Bot («Сапожный снос», Dota 2 Dark Carnival)

Пошаговая инструкция, как запустить бота и пройти мини-игру на автопилоте. Займёт ~5 минут.

---

## 1. Что понадобится

- **Windows** (10/11).
- **Dota 2** с активным ивентом **Dark Carnival** и доступной мини-игрой «Сапожный снос».
- **Python 3.12+** — [скачать](https://www.python.org/downloads/). При установке отметьте
  галочку **«Add Python to PATH»**.

## 2. Установка

Скачайте/склонируйте проект, откройте в его папке терминал (PowerShell) и поставьте зависимости:

```bash
python -m pip install -r requirements.txt
```

Это поставит `dxcam` (захват экрана), `opencv-python` (зрение), `pydirectinput` (нажатия),
`keyboard` (горячая клавиша стопа) и `pytest`.

## 3. Настройка игры

1. Запустите **Dota 2** → откройте ивент **Dark Carnival** → мини-игру **«Сапожный снос»**.
2. Поставьте игру в режим **окна без рамки (borderless) с разрешением 1920×1080** — под него
   бот откалиброван.
3. Доведите до экрана, с которого начинается игра (выбор позиции / первый запуск).

## 4. Запуск бота

В терминале в папке проекта:

```bash
python -m src.main
```

- У вас есть **2 секунды** (пауза по умолчанию), чтобы **кликнуть по окну игры** и сделать
  его активным — это важно: бот отправляет нажатия в активное окно.
- Дальше бот сам: запустит сапог → будет ловить его тележкой (клавиши **A/D**) → пройдёт
  уровень → запустит следующий. В консоли видно состояние и FPS.

### Аварийный стоп

- **F12** — мгновенно останавливает бота (нужен пакет `keyboard`, ставится из requirements).
- **Ctrl+C** в терминале — тоже останавливает. При любом выходе клавиши отпускаются.

> ⚠️ Пока бот работает, **держите окно игры активным**. Свернёте игру — она встанет на паузу
> (бот при этом не сломается, просто игра не идёт).

## 5. Полезные режимы запуска

| Команда | Что делает |
|---|---|
| `python -m src.main` | Обычный запуск: авто-пуск сапога + ловля. |
| `python -m src.main --manual` | Бот **только ловит**; сапог запускаете вы сами. |
| `python -m src.main --delay 5` | Увеличить паузу перед стартом до 5 с. |
| `python -m src.main --calibrate` | Проверить направление и скорость тележки (нажмёт D, затем A). |
| `python -m src.main --test-launch` | Прогнать только секвенцию запуска сапога (подбор таймингов). |
| `python -m src.main --log run.csv` | Записать CSV-лог сессии для диагностики. |

## 6. Если что-то идёт не так

**Тележка едет в противоположную сторону / ничего не ловит.**
Проверьте направление:
```bash
python -m src.main --calibrate --delay 3
```
Откройте экран, где тележка двигается по A/D, и посмотрите вердикт. Если написано
**«ИНВЕРСИЯ»** — поменяйте местами `KEY_LEFT` и `KEY_RIGHT` в [`src/config.py`](src/config.py).

**Сапог не запускается (автопуск молчит).**
Проверьте секвенцию отдельно:
```bash
python -m src.main --test-launch --delay 3
```
Если не стартует — увеличьте `LAUNCH_CONFIRM_PAUSE_S` и `KEY_TAP_HOLD_S` в `config.py`.

**Нажатия вообще не доходят до игры.**
Убедитесь, что окно игры активно и **не** запущено «от имени администратора» (тогда обычному
процессу может быть запрещено слать ввод — запустите терминал тоже от администратора).

**Другое разрешение, не 1920×1080.**
Геометрия поля задана в `config.py` (`FIELD_*_PX` при `REF_W/REF_H`) и масштабируется, но при
сильно ином разрешении пороги могут «поплыть». Снимите кадр `python -m src.capture --save
frame.png --delay 3` и подстройте пороги (см. `debug/overlay_frame.py`).

**Хочу понять, что бот видит.**
Запишите сессию `--log run.csv` — в CSV по каждому кадру: позиция сапога, тележки, цель,
команда и задержка. По нему легко понять, где именно бот ошибается.

## 7. Проверить, что всё собрано корректно

```bash
python -m pytest -q
```
Должно быть «39 passed» — это тесты логики и детекции (игра для них не нужна).
