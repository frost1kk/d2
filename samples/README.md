# samples — эталонные записи для анализа

Сохранённые «золотые» прогоны бота — источник правды при доработках (регресс, тюнинг стратегии).

## perfect-run.csv

CSV-лог образцовой сессии (формат `--log`): `frame, state, boot_x, boot_y, cart_x, target, direction, loop_ms`.

Снят на реальной игре после починки детекции блоков уровня 2+. Отработал **идеально**
(многоуровневый прогон без залипаний):

| Метрика | Значение |
|---|---|
| Кадров | 137 126 |
| Средняя задержка цикла | 2.8 мс (медиана 2.6) → **~353 FPS** |
| Время в игре (PLAY) | 121 126 кадров (**88%**) |
| Розыгрышей (PLAY-сегментов) | 932 |
| Переходов/перезапусков (крупные LOST) | ~40 |
| Ложная детекция (AIM) | 361 кадр (**0.26%**) — практически нет |

**Как пользоваться при доработках:** прогонять новую логику стратегии/детекции против этого
лога (как в `debug/detect_series.py` / офлайн-симуляциях) и сравнивать поведение — так мы
ловили баги, не запуская игру каждый раз. Не удалять и не перезаписывать: это baseline.
