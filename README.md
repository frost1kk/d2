## О проекте

«Сапожный снос» — Breakout-клон из ивента Dota 2 (Crownfall / Dark Carnival): сапог
отскакивает от тележки-платформы, разбивая блоки. Задача бота — ловить сапог: захват
экрана → детекция сапога/тележки → предсказание точки падения с учётом отскоков от стенок →
движение платформы.

**Цель окружения:** Windows, игра в режиме borderless 1920×1080.

## Как это работает

```
захват (dxcam) → детекция (OpenCV) → трекинг+предсказание → решение → ввод (pydirectinput)
```

Точка падения зависит только от **наклона** скорости сапога (vx/vy), поэтому скорость берётся
как разница позиций между кадрами — без привязки к реальному времени. Отскоки от левой/правой
стенок моделируются «треугольной волной» (`src/track.py: reflect_1d`). Подробности —
[LOGIC.md](LOGIC.md) и [ARCHITECTURE.md](ARCHITECTURE.md).

## Установка

```bash
python -m pip install -r requirements.txt
```

## Использование

**1. Снять опорные кадры** (для настройки детекции оффлайн):
```bash
python -m src.capture --save assets/frames/prelaunch.png
python -m src.capture --save assets/frames/inflight.png
```

**2. Проверить детекцию на кадре** (печатает координаты + сохраняет разметку):
```bash
python debug/overlay_frame.py assets/frames/inflight.png
```

**3. Запустить бота** (перехватывает клавиатуру — держи kill-switch наготове):
```bash
python -m src.main
```
Аварийный стоп: **F12** (если установлен `keyboard`) или **Ctrl+C**.

## Конфигурация

Все пороги и геометрия — в [src/config.py](src/config.py): ROI-соотношения поля, HSV-пороги
тележки/сапога, мёртвая зона управления, клавиши, бюджет цикла. Значения детекции — **первый
прикид**, требуют валидации на реальных кадрах (см. [BACKLOG.md](BACKLOG.md)).

## Структура

```
src/       capture · detect · track · control · input · main · config
tests/     юнит-тесты чистой логики (track, control)
assets/    frames/ — опорные кадры для оффлайн-тестов детекции
debug/     overlay_frame.py — визуальная проверка детекции
```

## Тесты

```bash
python -m pytest -v
```
Покрывают чистую логику (отскоки, предсказание точки падения, трекер, управление) — без игры.
Детекция и управляющий цикл проверяются на реальных кадрах / вживую (§3 CLAUDE.md).

## Ограничения и ToS

⚠️ Любой сторонний софт, автоматизирующий действия в игре, формально попадает под определение
читов Valve/Steam Subscriber Agreement — даже для одиночной ивент-мини-игры. Проект — **учебный
CV/automation**, без обхода анти-чита и вмешательства в процесс игры.
