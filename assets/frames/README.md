# assets/frames — опорные кадры для оффлайн-тестов детекции

Сюда кладём **реальные кадры игры** для проверки детекции без запущенной игры (§3 CLAUDE.md).

Ожидаемые имена (используются в отладке и тестах детекции):

- `prelaunch.png` — состояние «ВЫБРАТЬ ПОЗИЦИЮ»: сапог на тележке, ещё не запущен.
- `inflight.png` — сапог в полёте, тележка пустая внизу.

## Как получить кадры

Вариант А (рекомендуется — совпадает с реальным пайплайном захвата):
```bash
python -m src.capture --save assets/frames/prelaunch.png
python -m src.capture --save assets/frames/inflight.png
```

Вариант Б — сохранить присланные скриншоты игры под этими именами.

> ⚠️ Кадры, снятые `dxcam`, точнее для настройки порогов, чем внешние скриншоты: у них та
> же цветовая обработка и разрешение, что и в бою. Пороги в `src/config.py` — первый прикид,
> их валидируем именно на этих кадрах через `debug/overlay_frame.py`.
